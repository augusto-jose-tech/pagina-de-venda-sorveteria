# 🍦 Página de Venda - Sorveteria

Uma página de vendas moderna, responsiva e otimizada desenvolvida para atrair clientes e apresentar o cardápio de uma sorveteria de forma atraente.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes ferramentas:

* **HTML5** — Estruturação do conteúdo e semântica.
* **CSS3** — Estilização, design responsivo (Mobile First) e animações.
* **JavaScript** — Interatividade (como carrinho, modal ou transições).
* *[Se usou frameworks como React, Bootstrap ou Tailwind, adicione aqui]*

---

## 📋 Funcionalidades Principais

* 📱 **Design Totalmente Responsivo:** Adaptado para celulares, tablets e computadores.
* 🛍️ **Visualização de Cardápio:** Apresentação clara dos sabores, tamanhos e preços.
* 📍 **Seção de Contato & Localização:** Integração com mapas e links diretos para redes sociais/WhatsApp.
* ✨ **Interatividade:** Rolagem suave e efeitos visuais modernos para reter a atenção do usuário.

---

## 🔧 Como Executar o Projeto

Para baixar e rodar este projeto localmente, siga os passos abaixo no seu terminal:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd pagina-de-venda-sorveteria
   ```

3. **Abra o arquivo principal:**
   * Basta abrir o arquivo `index.html` diretamente em seu navegador ou utilizar a extensão **Live Server** no VS Code.
